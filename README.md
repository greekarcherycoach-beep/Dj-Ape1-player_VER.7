# Dj Ape1

Βιβλιοθήκη μουσικής με **Dj mode** (Automix, Smart Mix, επόμενο τραγούδι, playlists), ως εφαρμογή για Windows 10/11 (Electron).

## Τι περιέχει

| Αρχείο / φάκελος | Ρόλος |
|---|---|
| `app/index.html` | Η ίδια η εφαρμογή (το `music_library.html`) |
| `main.js`, `preload.js` | Παράθυρο, πρόσβαση στα αρχεία, αποθήκευση βιβλιοθήκης, tray, πλήκτρα πολυμέσων |
| `lib/` | Αρχεία ήχου με Range (seek), tags, αποθήκευση/backups, diagnostics, παρακολούθηση φακέλων |
| `assets/` | Εικονίδιο (`icon.ico`, `icon.png`) |
| `test/` | Αυτόματα τεστ (`npm test`) |
| `.github/workflows/build-windows.yml` | Χτίζει το `.exe` στο GitHub |

## Πώς βγαίνει το .exe (GitHub, χωρίς Windows στον υπολογιστή σου)

1. Ανέβασε όλο τον φάκελο σε νέο repository στο GitHub (`git init`, `git add .`, `git commit`, `git push`).
2. **Είτε** πήγαινε στην καρτέλα **Actions → Build Windows installer → Run workflow**, και όταν τελειώσει (~5 λεπτά) κατέβασε το αρχείο από τα **Artifacts**.
3. **Είτε** δημιούργησε release με tag:
   ```
   git tag v1.0.0
   git push --tags
   ```
   Το `.exe` εμφανίζεται μόνο του στο **Releases** του repository.

Παράγονται δύο αρχεία:
- `Dj-Ape1-Setup-<έκδοση>.exe` — εγκατάσταση (επιλογή φακέλου, συντόμευση στην επιφάνεια εργασίας και στο Start).
- `Dj-Ape1-Portable-<έκδοση>.exe` — χωρίς εγκατάσταση. Τα δεδομένα μένουν στον φάκελο `DjApe1Data` δίπλα στο αρχείο.

> Το πρόγραμμα δεν έχει ψηφιακή υπογραφή, οπότε στην πρώτη εκτέλεση τα Windows μπορεί να δείξουν «Windows protected your PC». Πάτα **More info → Run anyway**.

## Χτίσιμο τοπικά (σε Windows 10)

Χρειάζεται [Node.js 22](https://nodejs.org).

```
npm install
npm test
npm run dist          :: installer + portable, στον φάκελο dist\
npm start             :: δοκιμαστική εκτέλεση χωρίς εγκατάσταση
```

## Πού αποθηκεύονται τα δεδομένα

Στην εγκατεστημένη έκδοση: `%APPDATA%\Dj Ape1\`

- `library\library.json` — η βιβλιοθήκη (και `library.prev.json`, η προηγούμενη αποθήκευση)
- `library\backups\` — αυτόματα αντίγραφα ασφαλείας (τα τελευταία 15)
- `logs\diagnostics.log` — καταγραφή σφαλμάτων/καθυστερήσεων· ανοίγει από την εφαρμογή

Αν η εφαρμογή κλείσει απότομα, στην επόμενη εκκίνηση η βιβλιοθήκη ανακτάται αυτόματα.

## Σημειώσεις

- Το όριο μνήμης της εφαρμογής έχει αυξηθεί στα 8 GB για πολύ μεγάλες βιβλιοθήκες (30.000+ τραγούδια).
- Ο χρονισμός των crossfade συνεχίζεται κανονικά όταν το παράθυρο είναι ελαχιστοποιημένο.
- Πλήκτρα πολυμέσων (Play/Pause, Επόμενο, Προηγούμενο, Stop) λειτουργούν και με την εφαρμογή στο παρασκήνιο. **F11** πλήρης οθόνη, **F12** εργαλεία προγραμματιστή.
- Κλείσιμο στο tray και εκκίνηση με τα Windows: στις ρυθμίσεις της εφαρμογής.
